# Ad creative Centre — Savaro (COD Africa)

Video scripts + ad copy for every product in the Savaro Storeep store, in **English, Swahili and French**.

## Layout

- `products-index.md`: every product (duplicates ZW/ZM merged), its prices and which batch it is in.
- `batch-01/`, `batch-02/`, … one file per product. Each file holds:
  1. **Product brief**: who buys it, main angle, key benefits, prices
  2. **Video script A**: problem → solution, ~30 s
  3. **Video script B**: UGC / "I tried it", ~15 s
  4. **Hooks**: 3 extra opening lines per language, to test against each other
  5. **Ad copy**: long primary text, short primary text, 3 headlines, description, per language

## Rules used in every creative

- **COD first**: every CTA says pay cash on delivery. COD is the main trust trigger.
- **`[PRICE]` placeholder**: the store only has ZW (USD) and ZM (ZMW). The real prices are at the top of each file. Put in the price of the country you run in; Swahili/French countries need their own price.
- **Offer 1 / Offer 2** = the two options on the product page (usually 1 piece, then the bundle).
- **Meta ad rules**: for health products, never ask "Do you have diabetes / high blood pressure?" (personal attributes) and never promise a cure. Brand names you do not own (BaByliss, Rabanne…) are kept out of the ads.
- Scenes are written so they can be shot on a phone, or cut from supplier videos.
